# DormCare System — ระบบแจ้งซ่อมและจัดการข้อมูลหอพัก

เว็บแอปพลิเคชันสำหรับบริหารจัดการหอพัก รองรับการแจ้งซ่อมออนไลน์พร้อมแนบรูปภาพ การติดตามสถานะแบบเรียลไทม์ ระบบประกาศข่าวสาร และการจัดการผู้พักอาศัย

## คุณสมบัติหลัก (Features)
- **ระบบยืนยันตัวตน (Authentication):** แยกสิทธิ์การใช้งานระหว่าง **ผู้ดูแลระบบ (Admin)** และ **ผู้พักอาศัย (User)** ด้วย JWT
- **ระบบแจ้งซ่อมออนไลน์:** ผู้พักอาศัยสามารถแจ้งปัญหา พร้อมแนบรูปภาพและดูรูปภาพขยายขนาดเต็มได้ทันที
- **อัปเดตข้อมูลแบบเรียลไทม์ (Auto-Sync):** รายการแจ้งซ่อม สถานะการดำเนินงาน และประกาศจากหอพักอัปเดตอัตโนมัติทุก 5 วินาทีโดยไม่ต้องกดรีเฟรชหน้าเว็บ
- **โหมดกลางวัน / กลางคืน (Light / Dark Mode):** สลับธีมการแสดงผลได้จากแถบด้านบน และจดจำค่าที่เลือกไว้
- **ระบบจัดการหอพักสำหรับแอดมิน:** อัปเดตสถานะงานซ่อม โพสต์ประกาศ จัดการรายชื่อผู้พักอาศัย และสร้างบัญชีเข้าสู่ระบบประจำห้อง
