# DormCare – ระบบแจ้งซ่อมและจัดการข้อมูลหอพัก

เว็บแอปสำหรับหอพัก ให้ผู้พักอาศัยแจ้งซ่อม ดูประกาศ และชำระค่าเช่า ส่วนผู้ดูแล (admin) จัดการงานซ่อม ประกาศ บิล ผู้พักอาศัย และบัญชีผู้ใช้ได้จากที่เดียว

## ฟีเจอร์หลัก

| ฟีเจอร์ | ผู้พักอาศัย (user) | ผู้ดูแล (admin) |
|---|---|---|
| แจ้งซ่อม | แจ้งซ่อมพร้อมแนบรูป และดูเฉพาะรายการของตนเอง | ดูทุกรายการ เปลี่ยนสถานะ (รอดำเนินการ / กำลังแก้ไข / เสร็จสิ้น) และลบรายการ |
| ประกาศ | อ่านประกาศ | สร้างและลบประกาศ |
| บิลค่าเช่า | ดูบิลของห้องตนเอง แนบสลิปโอนเงิน | ออกบิล (ค่าเช่า + ค่าน้ำ + ค่าไฟ) ตรวจสลิป ยืนยัน/ปฏิเสธ และลบบิล |
| ผู้พักอาศัย | – | เพิ่ม/ลบข้อมูลผู้พักอาศัยของแต่ละห้อง (ชื่อ เบอร์โทร รูป) |
| บัญชีผู้ใช้ | – | สร้าง/ลบบัญชี (ต้องเหลือ admin อย่างน้อย 1 บัญชี) |

อื่น ๆ: ธีมมืด/สว่าง, ตัวกรองตามห้อง, หน้าเว็บดึงข้อมูลใหม่อัตโนมัติทุก 5 วินาที

## เทคโนโลยีที่ใช้

- **Frontend:** HTML, JavaScript, Tailwind CSS (CDN), Font Awesome, ฟอนต์ Prompt
- **Backend:** Node.js, Express 5, JWT (`jsonwebtoken`), `cors`, `dotenv`
- **Database:** PostgreSQL (ไลบรารี `pg`)

## วิธีติดตั้ง

### สิ่งที่ต้องมีก่อน

- [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (แนะนำรุ่น LTS)
- [PostgreSQL](https://www.postgresql.org/download/) และเครื่องมือ `psql`

### ขั้นตอน

**1) สร้างฐานข้อมูล**

```bash
psql -U postgres -c "CREATE DATABASE dorm_system;"
psql -U postgres -d dorm_system -f database/schema.sql
psql -U postgres -d dorm_system -f database/seed.sql     # ไม่บังคับ: สร้าง admin ตัวอย่าง
```

> `schema.sql` สร้างครบทั้ง 5 ตาราง: users, repair_reports, room_members, announcements, bills

**2) ตั้งค่า environment**

ไฟล์ `.env` ต้องอยู่ในโฟลเดอร์ `backend/` (เพราะรันเซิร์ฟเวอร์จากโฟลเดอร์นั้น)

```bash
# macOS / Linux
cp .env.example backend/.env

# Windows (Command Prompt)
copy .env.example backend\.env
```

จากนั้นเปิด `backend/.env` แล้วแก้ค่าให้ตรงกับเครื่องของคุณ

| ตัวแปร | ความหมาย | ค่าเริ่มต้นถ้าไม่ตั้ง |
|---|---|---|
| `PORT` | พอร์ตของเซิร์ฟเวอร์ | `3000` |
| `JWT_SECRET` | คีย์ลับสำหรับเซ็น token (ควรตั้งเป็นข้อความยาว ๆ ที่เดายาก) | `fallback-dev-secret` |
| `DB_HOST` | ที่อยู่ PostgreSQL | `localhost` |
| `DB_PORT` | พอร์ต PostgreSQL | `5432` |
| `DB_USER` | ชื่อผู้ใช้ PostgreSQL | `postgres` |
| `DB_PASSWORD` | รหัสผ่าน PostgreSQL | (ว่าง) |
| `DB_NAME` | ชื่อฐานข้อมูล | `dorm_system` |

**3) ติดตั้งและรัน**

```bash
cd backend
npm install
npm start
```

เมื่อเห็นข้อความ `Server running on http://localhost:3000` ให้เปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

> เซิร์ฟเวอร์เสิร์ฟทั้งหน้าเว็บ (ที่ `/`) และ API (ที่ `/api`) ในพอร์ตเดียว ไม่ต้องรัน frontend แยก

## วิธีใช้งาน

### เข้าสู่ระบบครั้งแรก

หากรัน `seed.sql` จะได้บัญชีผู้ดูแล `admin` / `admin1234` **ให้เปลี่ยนรหัสผ่านทันที** (หรือสร้างบัญชี admin ใหม่แล้วลบบัญชีนี้ในแท็บ “บัญชีผู้ใช้”)

### สำหรับผู้ดูแล (admin)

1. **บัญชีผู้ใช้:** สร้างบัญชีให้ผู้พักอาศัยแต่ละห้อง
   - ตั้ง **username เป็นเลขห้อง** (เช่น `101`) เพราะระบบใช้ username จับคู่กับห้องในบิล ผู้พักอาศัยจึงจะเห็นบิลของห้องตนเอง
2. **ผู้พักอาศัย:** บันทึกชื่อ เบอร์โทร และรูปของผู้พักอาศัยในแต่ละห้อง
3. **แจ้งซ่อม:** ดูรายการทั้งหมด กดดูรายละเอียด/รูป และเปลี่ยนสถานะเป็น “กำลังแก้ไข” หรือ “เสร็จสิ้น”
4. **ประกาศ:** สร้างประกาศถึงผู้พักอาศัย หรือลบประกาศเดิม
5. **บิล:** เลือกห้องและเดือน กรอกค่าเช่า และจำนวนหน่วยน้ำ/ไฟ ระบบคำนวณยอดรวมให้ (ค่าเริ่มต้น น้ำ 18 และไฟ 8 บาทต่อหน่วย) เมื่อผู้พักอาศัยส่งสลิปแล้วให้ตรวจและยืนยัน “ชำระแล้ว” หรือแจ้ง “สลิปไม่ถูกต้อง”

### สำหรับผู้พักอาศัย (user)

1. เข้าสู่ระบบด้วยบัญชีที่แอดมินสร้างให้
2. **แจ้งซ่อม:** กดสร้างรายการ ใส่หัวข้อ รายละเอียด และแนบรูป แล้วติดตามสถานะได้ในหน้าเดียวกัน
3. **ประกาศ:** อ่านประกาศจากผู้ดูแล
4. **บิล:** เปิดบิลของห้อง ชำระเงิน แล้วกดแนบสลิป สถานะจะเปลี่ยนเป็น “รอตรวจสอบสลิป” จนกว่าแอดมินจะยืนยัน

> QR Code ในหน้าชำระเงินเป็นภาพจำลองสำหรับการนำเสนอ ไม่ใช่ QR พร้อมเพย์จริง

## สรุป API

ทุกเส้นทางนอกจาก `/api/login` ต้องส่งหัวข้อ `Authorization: Bearer <token>` (token อายุ 1 ชั่วโมง)

| Method | Path | สิทธิ์ | หน้าที่ |
|---|---|---|---|
| POST | `/api/login` | ทุกคน | เข้าสู่ระบบ รับ token |
| GET / POST | `/api/reports` | ผู้ใช้ที่ล็อกอิน | ดู/สร้างรายการแจ้งซ่อม |
| PUT | `/api/reports/:id` | ผู้ใช้ที่ล็อกอิน | เปลี่ยนสถานะแจ้งซ่อม |
| DELETE | `/api/reports/:id` | admin | ลบรายการแจ้งซ่อม |
| GET | `/api/announcements` | ผู้ใช้ที่ล็อกอิน | ดูประกาศ |
| POST / DELETE | `/api/announcements[/:id]` | admin | สร้าง/ลบประกาศ |
| GET | `/api/bills` | ผู้ใช้ที่ล็อกอิน | ดูบิล (admin เห็นทุกห้อง) |
| POST | `/api/bills` | admin | ออกบิล |
| PUT | `/api/bills/:id/slip` | ผู้ใช้ที่ล็อกอิน | แนบสลิป |
| PUT | `/api/bills/:id/verify` | admin | ยืนยัน/ปฏิเสธสลิป |
| DELETE | `/api/bills/:id` | admin | ลบบิล |
| GET / POST / DELETE | `/api/members[/:id]` | admin | จัดการผู้พักอาศัย |
| GET / POST / DELETE | `/api/users[/:id]` | admin | จัดการบัญชีผู้ใช้ |

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| `password authentication failed` / เชื่อมต่อฐานข้อมูลไม่ได้ | ตรวจ `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` ใน `backend/.env` และตรวจว่า PostgreSQL เปิดอยู่ |
| `database "dorm_system" does not exist` | สร้างฐานข้อมูลตามขั้นตอนที่ 1 หรือแก้ `DB_NAME` ให้ตรงกับที่สร้าง |
| `EADDRINUSE` (พอร์ตถูกใช้แล้ว) | เปลี่ยน `PORT` ใน `backend/.env` |
| แก้ `.env` แล้วไม่มีผล | หยุดเซิร์ฟเวอร์ (Ctrl+C) แล้วรัน `npm start` ใหม่ และตรวจว่าไฟล์อยู่ใน `backend/` |
| ถูกเด้งกลับหน้าเข้าสู่ระบบ | token หมดอายุ (1 ชั่วโมง) ให้เข้าสู่ระบบใหม่ |
| ผู้พักอาศัยไม่เห็นบิล | username ของบัญชีต้องตรงกับเลขห้องในบิลทุกตัวอักษร |

## ข้อควรระวังด้านความปลอดภัย

- โค้ดปัจจุบันเก็บและเทียบรหัสผ่านเป็นข้อความธรรมดา ควรเปลี่ยนเป็นการเข้ารหัส (เช่น bcrypt) ก่อนใช้งานจริง
- ตั้งค่า `JWT_SECRET` เองเสมอ และไม่เผยแพร่ไฟล์ `.env`
- รูปภาพถูกเก็บในฐานข้อมูลเป็น base64 ซึ่งทำให้ฐานข้อมูลโตเร็วหากมีรูปจำนวนมาก
